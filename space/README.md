# tinytowns

A tiny letter-level GPT that makes up new town names in the style of real ones. The model runs in
your browser: this page downloads the weights from
[dave8172/tinytowns](https://huggingface.co/dave8172/tinytowns) and does every calculation on your
device.

Code and build steps: [github.com/dave8172/tinytowns](https://github.com/dave8172/tinytowns).
In your own code: `npm install @dave8172/tinytowns`.
